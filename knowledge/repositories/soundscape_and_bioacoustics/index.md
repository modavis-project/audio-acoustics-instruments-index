# Soundscape, bioacoustics, and ecoacoustics

Environmental soundscapes, biological sounds, ecological acoustic monitoring, and related analysis.

* [aschoeny333/Generalized-Power-Law-Detector](GHIAO-0284.md) - Software package for the detection and association of marine mammal calls in acoustic data
* [karolpiczak/ESC-50](GHIAO-0283.md) - ESC-50: Dataset for Environmental Sound Classification
* [MarineBioAcousticsRC/Triton](GHIAO-0280.md) - :whale: Scripps Whale Acoustics Lab   :earth_americas: Scripps Acoustic Ecology Lab - Triton with remoras in development
* [MitchellAcoustics/Soundscapy](GHIAO-0257.md) - A python library for soundscape assessments
* [npl16/ecoacoustic-vse-validation](GHIAO-0281.md) - Analysis scripts for the validation and pilot of a Virtual Sound Environment (VSE) for testing (spatial) ecoacoustic technologies.
* [QutEcoacoustics/audio-analysis](GHIAO-0279.md) - The audio analysis code (AnalysisPrograms.exe) for the QUT Ecoacoustics Research Group
* [scikit-maad/scikit-maad](GHIAO-0282.md) - Open-source and modular toolbox for quantitative soundscape analysis in Python
