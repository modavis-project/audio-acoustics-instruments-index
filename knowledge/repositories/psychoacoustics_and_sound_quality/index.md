# Psychoacoustics and sound quality

Auditory perception, listening experiments, perceptual metrics, sound quality, and auditory modelling.

* [acoustics-code-salford/refmap-psychoacoustics](GHIAO-0224.md) - REFMAP project task 4.3: Psychoacoustics of unmanned aerial vehicle (UAV) sound
* [AudioCommons/timbral_models](GHIAO-0395.md) - Python scripts for modelling timbral attributes
* [deeuu/loudness](GHIAO-0370.md) - Audio library for modelling loudness
* [Eomys/MoSQITo](GHIAO-0218.md) - MoSQITo is a unified and modular development framework of key sound quality metrics favoring reproducible science and efficient shared scripting among engineers, teachers and researchers community.
* [EtienneTho/musical-timbre-studies](GHIAO-0344.md) - Code und Daten für Studien zur menschlichen Wahrnehmung musikalischer Klangfarben.
* [ggrecow/SQAT](GHIAO-0219.md) - SQAT is an open-source repository of MATLAB codes implementing key metrics for sound quality analysis.
* [hagenw/amtoolbox](GHIAO-0230.md) - Mirror of the Auditory Modelling Toolbox http://amtoolbox.sourceforge.net/
* [HBB-ThinkTank/PALA](GHIAO-0364.md) - Python Audio Loudness Analysis
* [iver56/loudness](GHIAO-0351.md) - The world's fastest Python package for calculating integrated loudness (LUFS) from audio data as NumPy arrays
* [iwalton3/AutoEq](GHIAO-0317.md) - Automatic headphone equalization from frequency responses
* [Jencke/audiotoolbox](GHIAO-0229.md) - A python package for generating stimuli for auditory research.
* [MalcolmSlaney/LoudnessModel](GHIAO-0226.md) - Python code for calculating the perceived loudness of time-varying sounds
* [mandip42/psychoacoustics-tutorial](GHIAO-0225.md) - MATLAB and Python implementations of psychoacoustic metrics for automotive sound quality with case studies and ML workflows.
* [mlotinga/sottek-hearing-model](GHIAO-0223.md) - An implementation of the Sottek Hearing Model psychoacoustic sound quality metrics defined in ECMA-418-2.
* [PALILA-TUDelft/pySQAT](GHIAO-0220.md) - This repository contains the Sound Quality Analysis Toolbox (SQAT, originally developed in MATLAB in https://github.com/ggrecow/SQAT) translated to Python
* [porres/pd-psycho](GHIAO-0227.md) - Pd library with some psychoacoustic tools
* [slink/PsychoacousticMetrics.jl](GHIAO-0222.md) - Psychoakustische Modelle, Hörmetriken oder Sound-Quality-Analyse.
* [slink/ZwickerLoudness.jl](GHIAO-0221.md) - Zwicker loudness (ISO 532-1:2017) for stationary sounds in Julia — 1/3-octave SPL → sones/phons
* [tiianhk/timbremetrics](GHIAO-0343.md) - Metrics to test the alignment between audio models and human timbre perception
* [TUIlmenauAMS/PsychoacousticLoss](GHIAO-0228.md) - Psychoacoustic Loss Function
