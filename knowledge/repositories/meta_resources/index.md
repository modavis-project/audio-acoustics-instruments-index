# Curated lists and meta-resources

Indexes, catalogues, guides, and other curated resources that primarily point to relevant projects or knowledge.

* [alexarje/A-NIME-Reader](GHIAO-0008.md) - Source files for the anthology "A NIME Reader Fifteen Years of New Interfaces for Musical Expression"
* [comma-lab/timbre-resources](GHIAO-0014.md) - Kuratiertes Verzeichnis von Werkzeugen, Datensätzen, Literatur und weiteren Ressourcen zur Klangfarbe.
* [faroit/awesome-python-scientific-audio](GHIAO-0327.md) - Curated list of python software and packages related to scientific research in audio
* [Graphi07/room-impulse-responses](GHIAO-0149.md) - A list of publicly available room impulse response datasets and scripts to download them.
* [Intelligent-Instruments-Lab/intelligent-instruments-lab.github.io](GHIAO-0010.md) - Homepage for documentation of IIL GitHub repositories
* [landscape82/awesome-sound-design-resources](GHIAO-0286.md) - Awesome Sound Design resources
* [Nitnelav/awesome-acoustic](GHIAO-0285.md) - A list of awesome open-source acoustic packages and resources.
* [RAMshades/AcousticsML](GHIAO-0288.md) - Tutorial on using machine learning for acoustics. This tutorial covers a wide range of machine learning approaches for acoustic applications.
* [webprofusion/OpenAudio](GHIAO-0287.md) - A list of open source audio software projects (Apps, Plugins and Libraries). Please contribute more links or open source your own plugins.
