# Aeroacoustics, underwater acoustics, and ultrasound

Aeroacoustic, hydroacoustic, sonar, ultrasonic, or related wave-propagation research and tools.

* [1oly/AeroAcoustics.jl](GHIAO-0267.md) - A Julia package for Aeroacoustics
* [A-New-BellHope/bellhop](GHIAO-0272.md) - A mirror of the original FORTRAN BELLHOP underwater acoustics simulator, with some bugs fixed
* [A-New-BellHope/bellhopcuda](GHIAO-0273.md) - CUDA and C++ port of BELLHOP / BELLHOP3D underwater acoustics simulator
* [byuflowlab/FLOWUnsteady](GHIAO-0269.md) - An interactional aerodynamics and acoustics solver for multirotor aircraft and wind energy
* [gorbatschow/Sonar.m](GHIAO-0206.md) - Octave/Matlab toolbox for sonar related problems.
* [harshini-subbiah/Energy-aware-underwater-acoustic-communication](GHIAO-0276.md) - Adaptive Underwater Acoustic Communication Simulator using Energy-Aware Transmission and BELLHOP Channel Modeling in C.
* [jdbosser/GPU-Acoustics](GHIAO-0242.md) - Target strength (TS) calculation of 3D-models in the web browser using WebGL and three.js.
* [kmturbulenz/mglet-base](GHIAO-0249.md) - Multi Grid Large Eddy Turbulence
* [marlonsmathias/GATT_DNS](GHIAO-0250.md) - Direct Numerical Simulation code for the compressible Navier-Stokes equations. The linear stability analysis (LST) is done by a Jacobian-free time-stepping algorithm. The code was developed by the Group of Aeroacoustics, Transition and Turbulence of the São Carlos School of Engineering - University of São Paulo (EESC-USP).
* [OpenFAST/openfast](GHIAO-0278.md) - Main repository for the NREL-supported OpenFAST whole-turbine and FAST.Farm wind farm simulation codes.
* [org-arl/UnderwaterAcoustics.jl](GHIAO-0270.md) - Julia toolbox for underwater acoustic modeling
* [org-arl/VirtualAcousticOcean.jl](GHIAO-0271.md) - Real-time underwater acoustic simulator
* [polycfd/apecss](GHIAO-0238.md) - APECSS is a software toolbox to compute pressure-driven bubble dynamics and the resulting acoustic emissions.
* [QSOLKCB/TAS](GHIAO-0216.md) - The Topological Acoustic Stylus (TAS)
* [rpl-cmu/underwater-acoustic-pseudoranging](GHIAO-0275.md) - Code and Hardware Schematics for Underwater Acoustic Pseudoranging, presented at IROS 2022
* [signetlabdei/WOSS](GHIAO-0274.md) - WOSS is a framework that permits the integration of any underwater channel simulator that expects environmental data and provides a channel realization. WOSS integrates the Bellhop ray-tracing program. Thanks to its automation the user only has to specify the location in the world and the time where the simulation should take place.
* [TUSX/TUSX](GHIAO-0277.md) - Aero-, Unterwasser- oder Ultraschallakustik.
* [ucl-bug/jwave](GHIAO-0379.md) - A JAX-based research framework for differentiable and parallelizable acoustic simulations, on CPU, GPUs and TPUs
* [ucl-bug/k-wave](GHIAO-0232.md) - A MATLAB toolbox for the time-domain simulation of acoustic wave fields
* [unicfdlab/libAcoustics](GHIAO-0248.md) - libAcoustics - OpenFOAM library for far-field noise computation
* [Universite-Gustave-Eiffel/WAPE](GHIAO-0268.md) - Aero-, Unterwasser- oder Ultraschallakustik.
* [waltsims/k-wave-python](GHIAO-0233.md) - A Python interface to k-Wave GPU accelerated binaries
