# Physical and computational acoustics

General wave physics, numerical solvers, boundary and finite-element methods, and computational acoustic models.

* [bempp/bempp-cl](GHIAO-0236.md) - A fast Python based just-in-time compiling boundary element library
* [fbosio/elasticas](GHIAO-0215.md) - Estimation of elastic wave velocities in anisotropic solids
* [GAMMA-UMD/GWA](GHIAO-0360.md) - Geometric-Wave Acoustic dataset
* [IN03X/Boundary-Element-Method](GHIAO-0345.md) - Boundary-Element-Verfahren zur Berechnung von Schalldruck und Teilchengeschwindigkeit.
* [jinnsjj/ARD-simulator](GHIAO-0196.md) - 3D sound propagation simulator using adaptive rectangular decomposition method.
* [jotachango/adaptive-boxes-gpu](GHIAO-0239.md) - GPU-accelerated rectangular decomposition for sound propagation modeling :zap: :package:
* [lynspica/acoustic-logic-gates](GHIAO-0211.md) - Modelling the acoustic logic gates by solving the wave equation over the prescribed geometries by Wang, 2019 (DOI: 10.1038/s41598-019-44769-0)
* [mhamilt/1D-Wave-in-5-minutes](GHIAO-0213.md) - Reveal.js presentation and notes around the 1D wave equation and its modal frequencies
* [microsoft/AcousticScatteringData](GHIAO-0237.md) - Synthetic exterior acoustic scattering data and sample parsing code.
* [mipals/BoundaryIntegralEquations.jl](GHIAO-0240.md) - A simple package for solving Boundary Integral Equations using the (collocation) Boundary Element Method.
* [optimuslib/optimus](GHIAO-0235.md) - The official repository of OptimUS: a Python library for solving 3D acoustic wave propagation.
* [stuart-hawkins/tmatrom3](GHIAO-0244.md) - A numerically stable T-matrix package for 3D acoustics
