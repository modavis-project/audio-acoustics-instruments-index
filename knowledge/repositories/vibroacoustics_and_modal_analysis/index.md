# Vibroacoustics and modal analysis

Coupled structural-acoustic vibration, experimental or numerical modal analysis, and related tooling.

* [augucarv/FEM-acoustics](GHIAO-0245.md) - Open source MATLAB code for implementing a Finite Element Model in plates coupled with acoustic cavities. Contains the published paper.
* [dagghe/pyOMA2](GHIAO-0259.md) - Python module for conducting operational modal analysis
* [DrStS/STACCATO](GHIAO-0247.md) - STACCATO: STefAn's Computational vibroaCoustics Analysis TOol
* [ecker-lab/Optimizing_Vibrating_Plates](GHIAO-0266.md) - Code for the paper Minimizing Structural Vibrations via Guided Flow Matching Design Optimization
* [jotachango/vibro-acus-fem](GHIAO-0263.md) - Numerically Based Analyses of Fluid–Structure Interaction: Matlab and C++/CUDA implementation of FEM models.
* [minipief/pyva](GHIAO-0262.md) - Python toolbox for vibroacoustics
* [MOPT-UFSC/OpenPulse](GHIAO-0261.md) - Open Source Software for Pulsation Analysis of Pipeline Systems
* [MOPT-UFSC/VIBRA](GHIAO-0260.md) - Vibroacoustic Analysis using the Finite Element Method
* [permas4edu/permas4edu](GHIAO-0265.md) - Collection of finite element models
* [python-acoustics/Sea](GHIAO-0264.md) - DISCONTINUED - Statistical Energy Analysis (SEA) module for FreeCAD.
* [rivm-syso/OURS](GHIAO-0258.md) - Dutch calculation method for railway vibrations
