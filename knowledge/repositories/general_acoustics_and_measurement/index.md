# General acoustics and measurement

General acoustic analysis, instrumentation, calibration, measurement, and signal-characterization resources.

* [acoular/acoular](GHIAO-0188.md) - Acoustic testing and source mapping software
* [adrianSRoman/DeepWaveTorch](GHIAO-0290.md) - DeepWave: A Recurrent Neural-Network for Real-Time Acoustic Imaging (PyTorch implementation)
* [AppleHolic/neural_pitch_swipe](GHIAO-0346.md) - Make an simple pytorch module to approximate pitch. reference (https://pysptk.readthedocs.io/en/latest/generated/pysptk.sptk.swipe.html)
* [crlandsc/Acoustics_Suite](GHIAO-0209.md) - A suite of functions to perform acoustic calculations
* [D1mme/microphone_spotformer](GHIAO-0207.md) - This repository provides the MATLAB code for a certain type of microphone spotformer. A microphone spotformer is similar to a beamformer but considers regions-of-interest instead of directions.
* [DIMOSUS/Resonalyze](GHIAO-0201.md) - Car audio measurement and tuning for Windows: automatic time alignment, virtual DSP crossover, honest acoustic analysis
* [double2dev/online-tone-generator-mcp](GHIAO-0212.md) - An official MCP server for Online Tone Generator. Discover audio frequencies for instrument tuning, acoustic testing, meditation, and generate direct listening links.
* [drscotthawley/SoundFieldsForever](GHIAO-0202.md) - App Suite for Visualizing Sound in 3D
* [FastTune/FastTune](GHIAO-0051.md) - A tuner for guitar, ukulele, bass, banjo, mandolin, violin and etc.
* [fgnt/paderwasn](GHIAO-0190.md) - Paderwasn is a collection of methods for acoustic signal processing in wireless acoustic sensor networks (WASNs).
* [gregzanch/alpha-db](GHIAO-0214.md) - Alpha-dB is an api for acoustic properties of various materials and constructions
* [groupmm/libf0](GHIAO-0320.md) - A Python Library for Fundamental Frequency Estimation in Music Recordings
* [HidekiKawahara/FVN](GHIAO-0192.md) - FVN is now obsolete. Please use CAPRICEP instead. I will stop updating this tool. Frequency domain variants of Velvet Noise, a flexible building unit for speech synthesis, psychoacoustic research and acoustic measurement.
* [Iari-Lab/fpga_acoustic](GHIAO-0194.md) - Akustikmessung, akustische Signalverarbeitung oder allgemeines Analysewerkzeug.
* [instrumentbible/oscilloscope.js](GHIAO-0091.md) - JavaScript library for audio visualization. 📟
* [instrumentbible/tune.js](GHIAO-0092.md) - microtonal tuner built with Web Audio API  🎵
* [interactiveaudiolab/penn](GHIAO-0347.md) - Pitch Estimating Neural Networks (PENN)
* [jci24/SoundLens](GHIAO-0200.md) - AI-assisted acoustic investigation and product-sound benchmarking with deterministic DSP evidence.
* [jmrplens/A-Lab](GHIAO-0191.md) - Matlab-based software for measuring acoustic parameters and experiments.
* [jmrplens/phonometry](GHIAO-0187.md) - Standards-conformant acoustics library for Python: measurement and metrology, building, environmental and room acoustics, psychoacoustics, electroacoustics, vibration, underwater and aircraft/rotorcraft noise. Every method is implemented from the standard and validated against reference data, with teaching-style docs (formerly PyOctaveBand).
* [lars76/pitch-benchmark](GHIAO-0367.md) - Comprehensive benchmark suite comparing pitch detection algorithms across multiple datasets.
* [maxrmorrison/torchcrepe](GHIAO-0350.md) - Pytorch implementation of the CREPE pitch tracker
* [microphonon/acoustic-leak-detector](GHIAO-0195.md) - AquaPing is a battery powered, stand-off, acoustic leak detector
* [niigata-onkyo/oto-kako](GHIAO-0217.md) - [音加工班] 絵を描くように音を作るアプリケーション
* [ppklose/ppkSPLMeter](GHIAO-0231.md) - Config files for my GitHub profile.
* [pyfar/pyfar](GHIAO-0183.md) - python package for acoustics research
* [PyTTaMaster/PyTTa](GHIAO-0184.md) - Python in Technical Acoustics and Vibration
* [qpanpony/ita-toolbox](GHIAO-0186.md) - Akustikmessung, akustische Signalverarbeitung oder allgemeines Analysewerkzeug.
* [rabeaifeanyi/acoustic-camera](GHIAO-0193.md) - This project uses Acoular to implement an acoustic camera for the miniDSP UMA-16 microphone array, with optional integration of a transformer model.
* [self-noise/MikIRAM_GitHub](GHIAO-0210.md) - Mike's Impulse Response App for Matlab [MikIRAM] - Public version (GitHub)
* [sergiozc/multichannel-signal-enhancement](GHIAO-0208.md) - MVDR beamformer with sub-array configuration
* [sevagh/pitch-detection](GHIAO-0342.md) - autocorrelation-based O(NlogN) pitch detection
* [sharathadavanne/seld-net](GHIAO-0348.md) - Sound event localization, detection, and tracking of multiple overlapping and moving sources in 2D spherical space using convolutional recurrent neural network
* [sound-eng/arraytool](GHIAO-0199.md) - Simple acoustic line array simulator for theoretical study.
* [tlecomte/friture](GHIAO-0185.md) - Real-time audio visualizations (spectrum, spectrogram, etc.)
* [Universite-Gustave-Eiffel/acoustic-toolbox](GHIAO-0182.md) - A Python library for acousticians.
* [Universite-Gustave-Eiffel/CleanTiPy](GHIAO-0189.md) - An open-source implementation of CLEAN-T acoustic imaging technique
