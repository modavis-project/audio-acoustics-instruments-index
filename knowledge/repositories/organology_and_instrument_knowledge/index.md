# Organology and instrument knowledge

Instrument classification, ontologies, collections, terminology, cultural knowledge, and structured instrument data.

* [AudioCommons/ac-ontology](GHIAO-0396.md) - The Audio Commons Ontology
* [bdasgupta027/musical_instruments](GHIAO-0013.md) - Organologie, Instrumententaxonomie, Ontologien oder Sammlungsdaten.
* [davidfuhry/msc_thesis](GHIAO-0011.md) - Source repository for David Fuhrys master thesis on Image Based Digitization of Historical Music Storage Media
* [DDMAL/UMIL](GHIAO-0291.md) - The Virtual Instrument Museum website repository
* [digital-organology/hmsm](GHIAO-0006.md) - Tools for image based MIDI generation from historical music storage media
* [lucdoebereiner/OboeJS](GHIAO-0089.md) - Constraint-Based Generation of Oboe Fingering Sequences
* [metabrainz/irombook-instrument-images](GHIAO-0007.md) - Stores free instrument images made by IROMBOOK and available from their websites
* [MiniDraco/musical-instruments-master-list](GHIAO-0001.md) - 8,240-entry master list of musical instruments (4,448 unique), Hornbostel–Sachs classified, sourced per row. Available as CSV, JSON, SQLite, XLSX, TXT, and PDF.
* [modavis-project/musical-instrument-classes](GHIAO-0002.md) - JSON Databases for Musical Instrument Classifications based on the Hornbostel-Sachs System and Translations for Musical Instruments.
* [NatLibFi/SEKO](GHIAO-0004.md) - Translation project of the Finnish SEKO vocabulary
* [pencilresearch/midi](GHIAO-0349.md) - MIDI CC & NRPN database
* [philharmoniedeparis/mimo](GHIAO-0005.md) - MIMO tools & data
* [polifonia-project/bells-ontology](GHIAO-0387.md) - The Bell module represents concepts and relationships to describe bells, bell towers and bell ringers.
* [polifonia-project/music-instrument-ontology](GHIAO-0003.md) - This repository contains the Instruments ontology module of the Polifonia ontology network.
* [thegoose20/diss](GHIAO-0009.md) - Design Informatics Dissertation Visualizations
