# Musical instrument acoustics

Research and simulation centred on sound generation, vibration, radiation, or transmission in musical instruments.

* [aadjones/drum-vibes](GHIAO-0094.md) - Visualizing the vibrations of an ideal circular membrane
* [alexxior/TaPAS](GHIAO-0085.md) - Theoretical acoustics Plugin ⟿ Artificial Saxophones
* [calanuzao/thesis](GHIAO-0093.md) - Thesis Documentation
* [danftang/MusicalInstrumentSim](GHIAO-0087.md) - Experiments simulating musical instruments
* [equilet/tsar-bell](GHIAO-0386.md) - Max implementation of Faust code for Tsar Bell project
* [olivecha/guitarsounds](GHIAO-0016.md) - python library to analyse guitar sounds
* [Rhapsodizer/AcousticDataViewer](GHIAO-0088.md) - Web Application for Acoustic Data Visualization
* [tonykoop/didgeridoo](GHIAO-0086.md) - Stave-built didgeridoo design — 2013 acoustic study covering 25 musical keys (C1-C3, with build lengths from ~27" at C3 to ~107" at C1), frequency-to-length calculations, stave geometry across L:D aspect ratios 22:1 to 26:1, and design brainstorming for internal-rib patterns. Sister project to djembe and ashiko-drum-workshop.
