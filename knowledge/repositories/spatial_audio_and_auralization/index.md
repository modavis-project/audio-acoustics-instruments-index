# Spatial audio and auralization

Binaural, ambisonic, multichannel, localization, spatial rendering, and auralization technologies.

* [3DTune-In/3dti_AudioToolkit](GHIAO-0178.md) - 3D Tune-In Toolkit is a custom open-source C++ library developed within the EU-funded project 3D Tune-In. The Toolkit provides a high level of realism and immersiveness within binaural 3D audio simulations, while allowing for the emulation of hearing aid devices and of different typologies of hearing loss.
* [adct-the-experimenter/binaural-audio-editor](GHIAO-0171.md) - This is an audio application that produces 3D binaural audio from 2D mono audio samples and positional information given by the graphical user interface. Listen to 3D audio through stereo headphones. Video Demo:https://www.youtube.com/watch?v=peF9cZSwVGw
* [ahogg/HRTF-upsampling-with-a-generative-adversarial-network-using-a-gnomonic-equiangular-projection](GHIAO-0325.md) - Verfahren zur räumlichen Hochskalierung von HRTF-Daten mit generativen adversarialen Netzen.
* [ajintom/hrtf](GHIAO-0177.md) - An Auralization Framework for Virtual Acoustics
* [Any2HRTF/Mesh2HRTF](GHIAO-0234.md) - Open software for the numerical calculation of head-related transfer functions
* [AppliedAcousticsChalmers/acoustic-room-responses](GHIAO-0166.md) - Acoustic Room Responses in a Variety of Formats
* [AppliedAcousticsChalmers/auralization-toolbox](GHIAO-0164.md) - The Chalmers Auralization Toolbox
* [AppliedAcousticsChalmers/ReTiSAR](GHIAO-0165.md) - Real-Time Spherical Array Renderer for binaural reproduction in Python
* [AudioGroupCologne/SMATBIN](GHIAO-0173.md) - SMATBIN - Spherical Microphone Array To Binaural
* [Bk8/Auris](GHIAO-0150.md) - HRTF Auralization Engine Built with Juce
* [cesardsalvador/SpatialAcousticsLibraryMATLAB](GHIAO-0176.md) - A collection of MATLAB functions and scripts for spatial acoustic signal processing.

* [duyxsays/GNrator](GHIAO-0205.md) - Multichannel spatial audio data generator in cooperation with AAU & Jabra
* [EVERTims/auralization_engine_evertims](GHIAO-0145.md) - EVERTims Auralization Engine
* [facebookresearch/BinauralSDM](GHIAO-0326.md) - This repository contains a set of tools to render Binaural Room Impulse Responses (BRIR) using the Spatial Decomposition Method (SDM).The implementation features a series of improvements presented in Amengual et al. 2020, such as quantization of the direction of arrival (DOA) estimates to improve the spectral properties of the rendered BRIRs, or RTMod and RTMod+AP equalization for the late reverberation.The repository also contains the necessary files to 3D print an array holder of optimized topology for the estimation of DOA information.
* [facebookresearch/Paraspax](GHIAO-0340.md) - This repository contains code for the generation of binaural Room Impulse Responses using the Paraspax method and implementing a 6 DoF environment using optical tracking.
* [Ferdinando222/Upsampling-HOM](GHIAO-0358.md) - The official repository for the paper: "A Physics-Informed Neural Network-Based Approach for the Spatial Upsampling of Spherical Microphone Arrays
* [francesclluis/points2sound](GHIAO-0353.md) - A multi-modal neural network for binaural audio synthesis using 3D point cloud scenes
* [GrupoDiana/BRTLibrary](GHIAO-0170.md) - The Binaural Rendering Toolbox (BRT) is a set of software libraries, applications, and definitions aimed as a virtual laboratory for psychoacoustic experimentation. The BRT is developed in the framework of the SONICOM project and includes the algorithms developed in the 3D Tune-In Toolkit in a new open, extensible architecture.
* [IoSR-Surrey/3dti_AudioToolkit](GHIAO-0181.md) - 3D Tune-In Toolkit is a custom open-source C++ library developed within the EU-funded project 3D Tune-In. The Toolkit provides a high level of realism and immersiveness within binaural 3D audio simulations, while allowing for the emulation of hearing aid devices and of different typologies of hearing loss.

* [nightmoonbridge/vast_dft](GHIAO-0243.md) - A code repository for the accepted paper entitled "Fast Generation of Sound Zones Using Variable Span Trade-Off Filters in the DFT-Domain".

* [YeshiNamkhai/ResonatingWithYou](GHIAO-0026.md) - This repository offers an immersive sound experience designed to help people truly understand themself and their perception of the world.
