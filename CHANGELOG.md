# Changelog

All notable changes to the dataset are documented here. The project uses
semantic versioning for its public schema and curated catalogue.

## [Unreleased]

### Fixed

- Route the browser preview to rendered GitHub Pages documentation instead of
  GitHub Markdown source paths.

## [1.0.0] - 2026-08-25

### Added

- Initial public catalogue of 403 repositories.
- Fifteen controlled subject categories and core/adjacent scope classification.
- Canonical JSONL, CSV, JSON, SQLite/FTS5, Frictionless Data Package, RO-Crate
  1.3, and OKF 0.2 representations.
- Reproducible build, validation, GitHub metadata refresh, and release checks.
- Dataset citation, licensing, contribution, classification, and query guidance.
- A task-oriented README, reusable SQL/Python/jq examples, responsible-reuse
  checklist, and generated category overview.

### Changed

- Curator-reviewed primary categories and summaries after checking each record
  against the category definitions and the repository's documented purpose.
- README navigation, resource order, use cases, and explicit Open Knowledge
  Format (OKF) 0.2 guidance.
