# Code of Conduct

Participation in this project requires respectful, constructive, and
evidence-based communication. Harassment, discriminatory language, personal
attacks, intimidation, and deliberate disruption are not acceptable.

Repository inclusion and classification discussions concern the catalogue's
documented scope, not the worth of project authors or communities. Assume good
faith, explain disagreements with concrete evidence, and respect decisions made
through the published review criteria.

Report conduct concerns privately to the repository owner. Reports will be
reviewed confidentially and addressed in proportion to their severity.
